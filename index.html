手动导入 JSON

本工具只读 JSON、不解析文章。选一个 JSON 文件，或把 JSON 文本粘进来，点「载入」即开始阅读。 手上还没有数据的话，展开下面的提示词，让 AI 帮你生成。

载入数据

载入成功后弹窗自动关闭。也可以直接把 .json 文件拖到页面上。

没有 JSON？用 AI 生成

把下面这段提示词和英文文章一起发给任意 AI（ChatGPT、Claude、豆包等），它会返回可直接载入的 JSON。

        格式说明
        

          

            
              
title文章标题，显示在页面上方

sentences[].zh整句中文翻译

words.词.zh该词在本句语境中的义项

              
words.词.pos词性缩写，选填

              
words.词.ipa美式音标，选填
